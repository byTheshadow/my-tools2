# 深夜寿司屋 · 游戏规则

> 这份文档是规则的"唯一来源"。改数值时先改这里的说明，再改对应的代码位置（括号里标了在哪个文件）。

## 1. 一句话

在像素寿司屋里，按顺序完成 **捏饭团 → 放鱼片 → 上菜**，给点单的客人做对寿司，连击越高分越高。

## 2. 核心循环（每个寿司三步）

| 步骤 | 操作 | 要点 |
|---|---|---|
| 1 捏饭团 | 按住屏幕，松手 | 白圈从外向内收缩，缩到金色圈时松手 |
| 2 放鱼片 | 点一下 | 传送带上离中线最近的鱼片落到饭团上，要对准中线 |
| 3 上菜 | 点客人 / 点垃圾桶 | 点了这道寿司的客人才算对；不要的点右下角倒掉 |

电脑键盘：`空格` 捏饭团 / 放鱼片，`1 2 3` 给左 / 中 / 右客人上菜，`X` 倒掉。

## 3. 判定

### 3.1 捏饭团
白圈半径 `r` 离金圈中心 `13px` 的距离 `d = |r - 13|`：

| 条件 | 判定 | 结果 |
|---|---|---|
| `d ≤ 金圈半宽` | 完美 | 饭团饱满（捏度 0.7） |
| `d ≤ 金圈半宽 + 5` | 不错 | 饭团略歪（捏度取实际值，限制在 0.5–0.85） |
| 更远 | 失败 | 松手太早 → "太松，散了"；太晚 → "太硬了"；压到底 → "捏碎了"。失败后 0.35 秒内不能再捏 |

### 3.2 放鱼片
鱼片落下时与中线的水平偏差 `|dx|`：

| 偏差 | 判定 |
|---|---|
| ≤ 2.5px | 完美（正中） |
| ≤ 7px | 还行 |
| ≤ 13px | 歪了（仍然算放上去） |
| > 13px | 没放上：鱼片掉落，饭团保留，**连击清零**，可以再放 |

### 3.3 完美寿司
饭团 = 完美 **且** 鱼片 = 完美，有专属音效和粒子，分数 ×1.5。

## 4. 计分

```
基础分 = 饭团分 + 鱼片分 + 40 + floor(耐心剩余比例 × 30)
若是完美寿司：基础分 = round(基础分 × 1.5)
连击 +1
得分 = round(基础分 × (1 + min(连击, 20) × 0.1))
```

| 项目 | 完美 | 不错/还行 | 歪了 |
|---|---|---|---|
| 饭团分 | 30 | 15 | — |
| 鱼片分 | 30 | 15 | 5 |

单个寿司理论最高 **585** 分（完美寿司 + 耐心满 + 连击 20 层以上，倍率 ×3.0）。

## 5. 连击

- 每成功上菜一份 **+1**；倍率 `1 + min(连击, 20) × 0.1`，上限 ×3.0
- 以下情况 **清零**：捏饭团失败、鱼片没放上、上错菜、倒掉寿司、客人等不及离开
- 连击越高，难度越高（见第 7 节）

## 6. 客人

- 同时最多 **3 位**，固定三个座位；开局依次在 0.4 / 1.5 / 2.7 秒出现
- 每位客人随机点一种当前已解锁的寿司，头顶气泡显示订单和耐心条
- 耐心上限 = `max(12, 22 − 0.08 × 已过秒数)` 秒；耐心 < 30% 时客人会冒汗
- 耐心耗尽：客人生气离开 + 连击清零；离开后 0.8–2.2 秒会来新客人
- 上错菜：客人抖动、变脸，该客人 **不会** 因此离开，订单保留
- 传送带有 **55%** 的概率刷出"当前客人点的鱼片"，其余随机

## 7. 难度曲线

所有数值写在 `data/levels.js` 的 `difficulty`。

| 参数 | 公式 | 第一关数值 |
|---|---|---|
| 捏一个饭团的时间 | `max(min, start − 连击×perCombo − 秒×perSec)` | 1.15 − 0.02×连击 − 0.003×秒，最低 0.55 秒 |
| 金圈半宽 | `max(min, start − 连击×perCombo)` | 4 − 0.12×连击，最低 1.5px |
| 传送带速度 | `min(max, start + 秒×perSec + 连击×perCombo)` | 26 + 0.25×秒 + 0.6×连击，最高 62px/s |
| 客人耐心 | `max(min, start − 秒×perSec)` | 22 − 0.08×秒，最低 12 秒 |

## 10. 视觉与声音规范

- 逻辑分辨率 **180 × 320**，整数倍放大，`image-rendering: pixelated`
- 字体：DotGothic16（像素点阵体，联网时加载；离线用系统字体兜底）
- 主色板：墙面紫黑 `#3a2c3f`、柜台木色 `#a8653a` / `#e8b77a`、砧板 `#e5bf88`、饭米白 `#f7f2e6`、金色强调 `#f2b134`、警示红 `#ff6b5b`
- 声音全部由 WebAudio 合成，无外部文件；按住捏饭团时音调随压力升高
- 手机支持震动反馈（完美、失败、上错菜）

## 11. 教学夜

- 第一次点「开始营业」自动进教学夜；之后可在选关页第一行重练。不算在 8 夜里，不记最高分，不扣房租。
- 澄姐说话时全店暂停：传送带不动、客人耐心不掉、倒计时不走。点一下翻一句。
- 六步：打招呼 → 捏 2 个饭团 → 放 1 次鱼片 → 给客人上 1 份 → 倒掉 1 份 → 自由练习。前五步按需放开传送带和客人，自由练习才开始倒计时（75 秒）。
- 上菜那一步会固定来一位客人，点的正好是砧板上做好的那份，保证能成功。
- 失败不扣分也不打断，澄姐只安慰一句（每步一次）。
- 结算不报分数和称号，只有澄姐一句话，按上菜份数挑（0 / 4 / 8 份三档）。
- 脚本在 `js/data/tutorial.js`，判定与放开规则在 `js/tutorial.js`。

## 12. 经营与结算（步骤 3 已实现）

代码在 `js/economy.js`，数值在 `config.js` 的 `econ` / `run`，每夜的房租水电在 `data/levels.js`。

### 12.1 记账

```
营业额 = Σ（售价 × 售价倍率）+ Σ 打赏
今夜盈利 = 营业额 − 房租 − 水电 − 食材成本
累计资金 += 今夜盈利          （可以为负，亏本照样往下玩）
```

| 项目 | 规则 | 在哪调 |
|---|---|---|
| 售价倍率 | `1 + min(连击, 10) × 0.03`，最高 ×1.3（和计分倍率分开算，免得高连击把房租变成摆设） | `econ.moneyComboStep / moneyComboCap` |
| 打赏 | 完美寿司额外 +售价的 15% | `econ.tipRate` |
| 房租 | 每夜一个数，第 1 / 2 / 3 夜 = 200 / 350 / 550 | `levels.js` → `rent` |
| 水电 | 房租 × 10%，取整；之后想加难度可以调到 15%–20% | `levels.js` → `utilityRate`（不写用 `econ.utilityRate`） |

食材成本（每份的成本见 `data/dishes.js`）：

| 情况 | 记多少 |
|---|---|
| 上菜成功 | 整份成本 |
| 倒掉做好的寿司 | 整份成本 |
| 捏饭团失败 | 固定 6（`econ.riceFailCost`） |
| 鱼片没放上掉了 | 该鱼片成本的一半（`econ.fishMissRate`） |
| 上错菜 | 不记，订单和寿司都还在 |

| 菜 | 成本 | 售价 | 毛利率 |
|---|---|---|---|
| 玉子 | 16 | 50 | 68% |
| 三文鱼 | 22 | 60 | 63% |
| 金枪鱼 | 28 | 70 | 60% |
| 甜虾 | 32 | 80 | 60% |

**只有"当前这一夜"才记账。** 当前夜由存档里的 `night` 决定；回头重玩已通关的夜是**练习**（只记最高分，不动资金）。教学夜也不记账。

### 12.2 闭店线、回档、Game Over

- **闭店线** = −(当夜房租 × 2)（`run.closeLineRentMult`）。打烊后"资金 + 今夜盈利"**低于**闭店线就是闭店；恰好等于不算。
- **第 1、2 次闭店**：澄姐圆场，资金退回这一夜开始前的数值（存档 `nightStartMoney`），**夜数不变**，同一夜重做；`retries` +1。剧情进度、升级、图鉴、最高分全部保留。
- **第 3 次闭店 = Game Over**：`save.restartRun()`，回到第一夜，只清资金、夜数、重做次数。
- 重做次数是**一轮**一共 2 次（`run.retryMax`），过夜不会重置，只有 Game Over 才清零。
- 没闭店的打烊：资金入账，`night` +1（最多到已有关卡数）。
- 结算页：资金落到闭店线 × 0.5 以下（`econ.tightRatio`）但还没闭店时，账本底部多一行小字"账本有点紧了……"，并列出闭店线。

### 12.3 参考数据

用测试 bot 在真实游戏逻辑上跑出来的（每格 5 局平均，90 秒一夜）。bot 比真人稳，真人的上菜数通常更低，这张表只用来看相对松紧。

| 手艺 | 夜 | 上菜 | 今夜盈利 |
|---|---|---|---|
| 新手 | 1 / 2 / 3 | 14 / 13 / 17 | +293 / +23 / +3 |
| 普通 | 1 / 2 / 3 | 23 / 20 / 22 | +639 / +300 / +254 |
| 熟练 | 1 / 2 / 3 | 30 / 24 / 31 | +1275 / +609 / +850 |

第 2、3 夜是占位关卡（难度取草案夜 1 与夜 3 的中间值），步骤 8 会正式调数值，并切到 180 秒一夜。
